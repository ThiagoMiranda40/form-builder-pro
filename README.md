# Form Builder Pro

Quero um app web responsivo de cria formulários de inscrição:
- O benchmarking base para funcionamento pode ser o google forms;
- Eu, como administrador do sistema, quero poder criar formulários, cadastrar perguntas, escolher campos e tipos de campos que o usuário precisa preencher, personalizar meus formulários (inclusive o visual deles, cores, fontes, logotipo, nome/título, descrição);
- Eu como administrador do sistema, ao criar um novo formulário, preciso ter um link de compartilhamento para que usuários externos respondam ou preencham esse formulário;
- Esses formulários podem ser de inscrição de um evento, prova, quiz, etc. Pode solicitar tipos diversos de dados como texto, número, telefone, CPF e RG (ter algum recurso de validação do documento para não permitir preenchimento errado ou documento inexistente);
- Preciso escolher se quero limitar o preenchimento por quantidade de respostas, quantidade de inscritos, e/ou prazo por data e hora;
- Eu como administrador preciso ter uma área de admin onde crio/edito meus formulários e preciso de uma área onde visualizo os dados enviados (preenchidos) pelos usuários e preciso ter a opção de exportar esses dados em PDF e em planilha de Excel.
