# Kit de marca Corre Time

PNG com fundo transparente, exceto ícones, capas, cartões e timbrado. Regras de uso: ver *Manual da Marca Corre Time*.

## Variações de cor
- `cor-positivo`: marinho + laranja, para fundos claros
- `cor-negativo`: branco + laranja, para fundos marinho/escuros
- `sobre-laranja`: marinho + branco, para fundo laranja #FF5B1F
- `mono-preto` / `mono-branco`: uma cor (carimbo, gravação, silk de uma cor)

## Pastas
- `01-logo/` horizontal (600–4800 px), vertical e logotipo (600–2400 px)
- `02-simbolo/` símbolo isolado, 256–2048 px
- `03-app/` iOS (App Store 1024 + tamanhos do Xcode), Android (Play Store 512, ícone adaptativo 432 com frente/fundo/monocromático, mipmaps), splash
- `04-web/` favicon 16/32/48, apple-touch-icon 180, ícones PWA 192/512 + maskable, imagem de compartilhamento (OG) 1200×630
- `05-redes-sociais/` avatar 1080 (marinho, laranja, papel), capas LinkedIn, X, Facebook, YouTube, post 1080×1080 e story 1080×1920
- `06-camisetas/` 300 dpi: peito 10 cm, costas 28 cm, manga 6 cm
- `07-papelaria/` 300 dpi: cartão de visita 85×55 mm (frente/verso, sangria 3 mm), papel timbrado A4, capa de documento A4, logo para assinatura de e-mail (300/600 px)

## Cores
- Marinho #101B33 · RGB 16 27 51 · CMYK 69 47 0 80
- Laranja-sinal #FF5B1F · RGB 255 91 31 · CMYK 0 64 88 0
- Papel #F5F3EE

CMYK é conversão de referência: faça prova de cor na gráfica.

## Observações
- Para silk, bordado e impressão em grande formato, a gráfica pode pedir arquivo vetorial (SVG/PDF/AI).
- Cartão de visita (verso): os textos são campos de exemplo e precisam ser substituídos.
- Fonte: Archivo (Google Fonts), versão expandida 800 na marca.
